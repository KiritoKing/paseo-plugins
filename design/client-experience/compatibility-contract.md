# 会话阅读兼容合同

会话阅读已并入 Essentials，独立主题包移除。这里约束正文、工具和思考的呈现模块；Essentials 原有的附件、图片查看和会话恢复遵循各自的公开接口与权限边界。当前证据与未验证范围见[验证记录](../../packages/paseo-ux/VALIDATION.md)，迁移前结果见[历史记录](evidence/codex-ui-history.md)。

## 能力与归属

会话阅读仅使用公开 timeline、settings 和 React Native API，消费宿主传入的主题 token，不注册主题。Paseo 继续拥有侧栏、路由、pane、composer、权限、模型与运行控制；不新增工作概览、审阅中心或执行流程。该模块不增加文件／Git RPC、生命周期自动化、全局事件或 DOM 补丁。

完整助手正文中受支持的 Markdown 可以改排版；流式正文、图片、附件、混合媒体、未知结构与超限内容交回原生。逐条 shell 记录为可选，默认保留原生工具分组。思考默认折叠，内容与复制保留。

## Timeline 协作

Paseo 的 transformer 采用第一个有效输出；`undefined` 才继续，空数组同样认领。不能靠安装名称或加载顺序保证多个插件叠加。[历史源码与直接探针](evidence/compatibility-sources.json)绑定的是官方 0.11.4 源码，不代表新的集成验收。

Essentials 内的图片画廊与正文排版按内容分工：纯图片消息可由画廊认领，正文模块对图片返回 `undefined`；混合图片与文字交回原生。组合测试必须覆盖两种注册顺序、流式阶段、媒体开关和会话阅读总开关。

“全部折叠（仅输出）”是用户主动选择的显示过滤。它统一隐藏工具与思考及标题，包括未知工具与失败记录，但不修改原始历史、权限提示或运行控制。切回分类设置恢复已有偏好，切换模式重新注册相应 transformer，以使已显示记录更新。

同类消息仍不应同时启用多个呈现插件；迁移完毕后卸载旧主题插件。renderer 缺失、schema 错误和组件异常不能被描述为必定恢复原生，因此应在认领前校验内容与能力，注册失败后释放本模块的认领。

## 设置与迁移

Essentials 的安装 ID 仍为 `paseo-ux`，包名仍为 `@chlrc/paseo-ux`。原 `media` 设置保留；会话阅读使用独立的 `appearance` 设置、version 1，与旧偏好兼容。关闭会话阅读不能关闭附件或会话历史，关闭媒体也不能改变正文偏好。

设置属于所选 host，使用原生 revision 冲突和 invalid 状态，不当作设备本地或跨 host 全局数据。迁移是对应 daemon 上的一次管理操作：先备份两个插件，再按[迁移说明](../../docs/migration.md#会话阅读并入-essentials)保留完整偏好。运行模块不扫描其他插件设置，不静默覆盖已存在的目标偏好。

移除主题后，由 Paseo 自身处理已选主题的回退。Essentials 不修改用户的主题选择、provider、权限或其他插件设置。

## 生命周期与版本

会话阅读只维护自己的一份设置观察，不逐行建立订阅。重连重新读取设置；设置读取失败、能力缺失或卸载后，不继续认领消息。清理覆盖 transformer、renderer、设置入口及异步等待，不能让较早请求在卸载后恢复贡献。

最低版本声明为 Paseo `>=0.11.2`，开发 SDK 为 0.11.2，本轮实际 App／daemon 为 0.12.0。历史隔离声明编译只对应其记录的源码 revision，不能扩大为迁移后代码或全部版本的运行证明。升级时需重新检查公开 API 与组合回归，不加入私有接口以维持表面可用。

## 验收矩阵

| 场景 | 验证目标 |
| --- | --- |
| 正文、图片、混合消息与流式更新 | 内容完整，原生回退与画廊分工正确 |
| 仅输出、分类设置与总开关 | 原始历史保留，切回恢复偏好，其他 Features 独立 |
| 失败记录、长内容、展开与复制 | 状态真实、完整细节可达、错误反馈稳定 |
| 浅深主题、宽窄窗口、键盘与触控 | 使用宿主 token，布局可读，原生输入与运行操作保留 |
| 读取失败、重连、卸载与晚到请求 | 不错误认领消息，不残留订阅或恢复注册 |
| 旧偏好迁移与已有 Essentials 设置 | 阅读偏好保留，媒体设置不被覆盖，旧插件退出 |

本地检查、合成组件夹具、真实插件加载、原生实屏与设备验收分别记录，不把 running 或类型检查写成全部客户端交互通过。
