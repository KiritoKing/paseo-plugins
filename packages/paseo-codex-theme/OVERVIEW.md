# Codex Theme

为 Paseo 提供 Codex 风格的浅色与深色配色。在设置 → 外观选择 Codex Light 或 Codex Dark：浅色采用白底与浅灰面板，深色采用炭灰底与分层面板，两者均使用黑白强调色和柔和灰色边框。

主题通过 Paseo 原生外观系统覆盖菜单、聊天、插件面板与终端。这是独立设计的配色，不是官方 Codex 主题或完整布局复刻；字体、间距和功能保留 Paseo 的原有实现。安装不会自动切换主题，禁用插件后 Paseo 回退到默认主题。

需要 Paseo 0.11.2 至 0.11.x。插件只有客户端主题数据，不读取文件或会话，不发送网络请求，也不隐藏任何消息或控件。
