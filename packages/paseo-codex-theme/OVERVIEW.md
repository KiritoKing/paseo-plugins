# Codex UI

优化 Paseo 现有会话的阅读体验：调整正文标题、列表、引用、代码块与阅读宽度，思考记录可折叠、选择和复制。默认保留原生工具分组；可选的逐条工具记录支持展开查看完整命令、输出、错误和退出码。原生输入、运行控制、权限操作、侧栏和其他插件入口保持原有归属。

在设置 → 插件 → Codex UI → 会话外观中调整字号、密度、代码换行和默认展开方式。流式正文、图片、附件、表格、文件链接、未知工具和超限内容使用原生呈现。使用其他聊天呈现插件时，可按工具、思考和正文分别关闭本插件的增强。

在设置 → 外观中可另选 Codex Light 或 Codex Dark，也可以保留当前主题。安装不会自动切换配色。这是独立设计的体验插件，与 OpenAI 无隶属关系。

最低版本为 Paseo 0.11.2，当前运行验收目标为桌面版 0.11.4。0.12.0 的公开 API 声明另作静态兼容检查，未将其视为运行验收。呈现使用公开插件接口和 React Native 组件；本插件不改写全局页面结构。偏好由当前 host 的原生设置系统保存，文本仅在客户端排版，不发起额外的模型请求、文件读取或外部数据上传。
