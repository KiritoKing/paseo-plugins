- 完整 `pnpm check` 通过：环境、Biome、公开文件、导入边界、三包类型检查、49 项业务测试与 14 项工具链测试、五份浏览器夹具构建及三包隔离打包／入口编译。

## 浏览器真实组件

统一夹具 `/conversation-ui.html` 使用真实呈现组件、React Native Web 和合成数据。设置 UI、复制、链接打开和文本揭示的 host 适配由夹具替代。

已验证宽屏浅色、390px 深色、标题层级和链接名称、工具失败自动展开、完整细节可达、键盘收起、复制成功／失败反馈、保存失败保留已保存值，以及关闭增强后释放对应 transformer。复制检查验证了组件调用和反馈，没有把模拟复制当成真实客户端剪贴板验收。

`assets/conversation.jpg` 是实际组件截图，开启可选逐条工具样式；默认仍保留原生工具聚合。图中测试计数属于合成样本，不是本插件的执行结果。

## 真实 Paseo

App 和 CLI 为 0.11.4。候选使用独立测试安装 ID，原有稳定主题安装保留。daemon 的候选加载与无错误运行已读回；客户端曾出现实际工具呈现，并通过公开导航 API 在临时验收副本中打开原生外观设置，读回开关与默认值。临时自动导航代码已清除。

原生截图捕获成了插件列表，与设置页的界面树不一致，该截图已剔除；收尾只读捕获又返回 `cgWindowNotFound`，未将其记作最终界面验收。Paseo browser 创建标签页超时，因此浏览器组件验收使用已连接的外部浏览器。

现有媒体、Companion 和侧栏插件保持运行，但 running 状态与入口可见性只构成共存冒烟证据，不能代替各插件全部功能回归。

预览浏览器标签页与本任务的开发服务已回收，相关端口已检查；临时工具链 shim 在收尾后移除。原有稳定主题安装保留，候选独立加载以便试用。
