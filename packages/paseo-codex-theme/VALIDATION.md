# Codex UI 候选验证

## 2026-10-21 增量：减轻浅色选中底色

- 浅色 `ring` 从 `#969696` 调整为淡蓝灰 `#e4edf9`，其余配色及深色主题保持不变。选中行标题／次要文本的计算对比度为 15.03:1／4.51:1；原底色上的次要文本为 1.80:1。
- 已核对 [Paseo 0.12.0 的主题映射](https://github.com/getpaseo/paseo/blob/v0.12.0/packages/app/src/plugins/themes/index.ts)与[浅色语义派生](https://github.com/getpaseo/paseo/blob/v0.12.0/packages/app/src/styles/theme.ts)：浅色侧栏选中底色使用 `ring`，不是 `accent`。公开接口同时将该值用于更弱的提示色、滚动条及终端 bright black，尚不能独立指定这些颜色；本轮没有加入私有样式覆盖。原生控件的键盘焦点继续使用蓝色 `accent`。
- 本轮只修改颜色与说明，进行定向类型、样式和公开文件检查及现有本包测试。插件重载后的运行状态独立读回；原生控制目前只读到了另一深色窗口，浅色窗口的最终实屏效果未复核，不能用该深色截图作本轮验收。

App 和 CLI 为 0.11.4。候选使用独立测试安装 ID，原有稳定主题安装保留。daemon 的候选加载与无错误运行已读回；客户端曾出现实际工具呈现，并通过公开导航 API 在临时验收副本中打开原生外观设置，读回开关与默认值。临时自动导航代码已清除。

现有媒体、Companion 和侧栏插件保持运行，但 running 状态与入口可见性只构成共存冒烟证据，不能代替各插件全部功能回归。

预览浏览器标签页与本任务的开发服务已回收，相关端口已检查；临时工具链 shim 在收尾后移除。原有稳定主题安装保留，候选独立加载以便试用。
