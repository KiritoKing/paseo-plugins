AIW Companion 在 AIW 工作区中提供按子仓聚合的文件树、代码阅读和 Git Diff，以及独立的跨仓文本搜索。

“AIW 业务仓”提供文件和改动两种视图，支持分支全部变更、已提交变更、未提交变更。筛选按对比范围、文件类型分组；文件树支持目录折叠，全文和 Diff 提供语法高亮、固定行号及折行。“代码文件”和“文档文件”按两套独立路径 pattern 从当前 Diff 中筛选，使用同一个阅读器。右上角设置图标直接打开 Pattern 编辑弹窗，树顶部提供刷新和折叠图标，内置常见源码扩展名及 Markdown、OpenSpec、AIW 文档规则，支持自定义 Include/Exclude，不绑定需求框架。

“AIW 跨仓搜索”拥有独立查询和仓库范围，可查未改动文件。点击命中跳转到文件和行号。

文件树与预览之间可拖拽调整，树顶部图标切换左右或上下布局。布局按宿主机和工作区记忆，关闭后重新打开会恢复；窄面板临时上下排列，并保留原来的偏好。

需要 Paseo 0.11.1 或更高版本、Git、ripgrep（rg），以及已有 AIW CLI。工作区有工具链锁文件时严格校验版本；无锁文件时支持宿主机安装，通过实际状态和 Git 身份核验。已选但未物化的业务仓显示未就绪原因。插件不会自动下载、物化或修复业务仓。未物化或不是 AIW 的工作区会显示原因。

后端读取当前 daemon 上的 AIW 清单、托管业务 worktree、Git 状态和文件；项目 pattern 偏好持久化在当前 host 的插件设置中。文件和 Diff 首版只读，不执行提交、暂存、push 或业务代码写入。文件读取和搜索有大小、结果数与超时上限。

根目录有 aiw.yaml 的工作区会显示两个顶部入口，点击后在右侧 Explorer 打开业务仓、搜索页签。插件只检查配置文件是否存在，不要求先物化业务仓；配置变化每分钟刷新，普通工作区不显示入口。面板按实际宽度适配较窄的侧栏。
