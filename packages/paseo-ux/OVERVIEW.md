# Paseo Essentials

Paseo Essentials helps you read conversations, inspect each turn's Git changes, browse attachments, view images, and return to workspace sessions. It adds Markdown and code layout, collapsible reasoning, optional shell records, and an output-only reading mode. It also groups complete image-only messages into compact galleries, provides a searchable attachment panel, and lets you browse and reopen restorable sessions in the current workspace.

Turn changes adds a card after a turn that changes files or creates commits. Select a file to open its saved diff or before-and-after image preview. View all changes opens the recorded turn; the Command Center action opens retained history for the selected agent. Cards list up to 20 files and 10 commits. Concurrent turns sharing a Git worktree show a warning about attribution. Git must be available on the daemon host and the repository must have an existing commit. This independently implemented feature follows the behavior of HiepPP's Turn Diff; enabling multiple turn-card plugins can produce duplicate cards.

Conversation reading controls font size, density, width, code wrapping, and disclosure. Output-only mode hides tool and reasoning rows without deleting history; switching back restores category preferences. Native tool grouping is the default. Streaming prose, rich or unsupported messages, and unknown tools retain host rendering. The reading controls are independent of media and session features and follow the active Paseo theme; the plugin does not provide themes.

Image-only assistant and user messages are displayed as galleries; mixed text remains in Paseo's renderer. The full-screen image viewer supports touch gestures and, on desktop, mouse wheel zoom, drag pan, double-click reset, and arrow-key image navigation. The attachment panel indexes references in the selected conversation's public timeline and structured tool results. Search by name or path, filter by media type, and load older history. The composer entry appears after the metadata index finds attachments in the conversation.

The index covers references exposed in the host's message text and tool details. It follows the host's merged conversation view; it does not recover old tool details or separate attachment payloads omitted from that history.

Paseo 0.11.2 or later is required. Reopening a session uses the public Paseo CLI on the daemon host. The executable must be available on that host's PATH. PASEO_HOME selects the daemon data directory and defaults to ~/.paseo; PASEO_ESSENTIALS_CLI can select a different executable. The plugin does not require a separate account, token, or model. Preferences are scoped to a host and apply to devices connected to it.

Settings control turn changes, attachment indexing, image grouping, visible thumbnail count, image gestures, session history, and audio playback. These switches default to on. Turning off turn changes stops new snapshots and hides its cards and command without deleting retained history. The thumbnail count ranges from 1 to 8 and defaults to 3. Supported local audio can be played on request. Video, PDF, and other files appear as attachment cards; the plugin has no in-app video player or PDF reader. Native iOS and Android behavior has not been verified on real devices.

For attachments, the daemon reads public conversation history and structured tool results without scanning workspace directories. Before reading local image or audio content, it confirms that the source appears in the conversation history; a referenced path can resolve outside the workspace. Local image and supported audio reads are limited to 16 MiB. HTTP(S) sources open through Paseo's external URL handler; the daemon does not fetch them.

Turn changes snapshots tracked and eligible untracked files at turn boundaries using a temporary Git index. Ignored untracked files are excluded; untracked files over 1 MiB are listed without saved contents. Snapshot contents remain in the repository's Git object database under refs/paseo-ux/turns; mirror pushes include these refs. Owner-only metadata is stored under PASEO_HOME/plugin-data/paseo-ux/turn-diff, defaulting to ~/.paseo/plugin-data/paseo-ux/turn-diff. When history first loads and after recording a turn, it prunes records older than 30 days or beyond 2,000 and their refs; unreferenced objects remain until Git garbage collection. Pending starts survive plugin reload for up to one day. The panel reads persisted history when timeline cards are no longer available.

Diff and image reads require a recorded agent, turn and file. Diff previews are limited to 200,000 characters and 2,000 rendered rows; images over 3 MiB are not previewed. Non-Git directories, repositories without a commit, or missing start snapshots produce no card. Snapshot failures cannot reconstruct missing changes. Diff text and image data are sent to the connected Paseo client through RPC. The plugin makes no network requests for turn changes and does not send conversation content to an additional model; agent messages follow the selected provider's existing Paseo configuration.

Capture stops at 50,000 paths, 1 GiB of input or 120 seconds per snapshot. Oversized untracked files are compared by size, modification time and mode without saving their contents; edits preserving that metadata cannot be detected.
