**全窗口图片查看器**

图片查看独立于通用窄弹窗。目标是铺满当前应用窗口的可用空间：图片保持比例，按实际画布计算适应尺寸；窗口缩放、分屏、手机旋转与折叠屏尺寸变化时重新计算，不沿用固定预览宽高。

桌面保留紧凑工具栏；来源等次要信息收进详情，缩略图条可收起。手机采用全屏查看、单击显示或隐藏工具栏，按钮保持触控可达。支持双指缩放、缩放后拖动、复位；适应状态下才用横向滑动切图，放大后横向手势用于平移。基础上一张、下一张和复位按钮始终可达。

Paseo 0.12 的通用 `Modal` 只有内容布局参数，没有公开全屏尺寸选项。实施第一步验证 React Native 公开 `Modal` 在 Paseo 插件运行时的全窗口呈现、焦点与安全区域；若所需能力没有公开接口，使用 `addScreen` 承载的满内容区查看页，并将覆盖整个窗口的差异明确交由讨论。禁止通过 CSS 或宿主 DOM 修改通用弹窗尺寸。Android 返回、Web Escape、关闭后的焦点恢复和宿主允许的旋转均需实测。

触控和尺寸响应优先使用 `PanResponder`、`Image`、`onLayout`、`useWindowDimensions` 等公开 API。桌面鼠标或键盘增强限定在查看器自己的交互范围内，只有公开接口支持时接入，不修改全局事件原型或宿主快捷键。

**会话附件与入口显隐**

面板建议改称“会话附件”，统一收纳图片、视频、音频及普通文件。分类只在实际存在该类资源时出现；不能预览的文件仍显示附件卡片，不因缺少播放器而消失。

会话里的自动附件入口仅在发现至少一个附件后显示。确认没有附件时隐藏入口及其占位，也不自动打开面板；通过 `PluginButtonRegistration.update({visible})` 控制。用户已经打开的面板不因刷新结果变化突然关闭，搜索无结果也不隐藏搜索所在面板。

索引区分未知、检查中、已发现、确认空与失败。当前只读取最近 200 条历史，不能据此断言整个会话没有附件；较早历史按游标有界续查，第一次发现附件即可显示入口，只有覆盖完成才能确认空。失败保留错误状态和已有非空缓存，不当作无附件；手动命令提供刷新和重试入口。索引按 host、agent、epoch 和游标隔离，通过公开会话事件增量更新，不依赖 DOM 或不断扫描所有会话。

索引阶段只处理引用与必要元数据，不加载原始二进制，不扫描工作区目录。扩展普通 Markdown 文件链接和结构化附件来源，同时继续排除代码示例。服务端统一记录类型、MIME、来源、可取得的大小与可用预览能力，普通文件不伪装成图片。

**预览能力与 API 边界**

| 类型 | 设计目标 | 已核实的公开能力与缺口 |
| --- | --- | --- |
| 图片 | 大空间查看、缩放、切换与详情 | React Native 图片与公开手势 API 可用于插件自有界面；具体宿主呈现待验收 |
| 音频 | 用户点击后播放，明确加载与失败状态 | `client.playAudio` 支持跨平台播放；不能据此承诺暂停、拖动进度或流式播放等未暴露控制 |
| 视频 | 首发纳入附件列表，内置播放后续补齐 | 当前公开插件模块未提供视频播放器；首发仅提供已核实可用的官方操作，后续接入正式跨平台播放与资源访问扩展 |
| PDF 等文档 | 识别与附件卡片，具备正式能力后接入预览 | 当前查到的插件 SDK 未提供通用文件预览器，不能将任意二进制标为可预览 |
| 其他二进制 | 展示名称、类型和可取得的大小 | 文件打开、下载和客户端落地需要实际公开接口支撑；不读取或执行文件内容来假装预览 |

公开 `openExternalUrl` 可打开 HTTP(S) 来源，但不等于视频已在插件内播放。远端 daemon 的本地路径不能直接当作手机或桌面客户端的 `file://`。本地大视频需要正式授权资源 URL、范围读取或等价传输 API；不把整段视频塞进图片式 base64 RPC。未核实可用的下载接口前，不展示必然失败的下载按钮。

视频首发验收为可发现、可分类、可展示附件卡片，并准确标明可用操作。内置播放列入后续版本，届时单独验收正式播放器、文件访问与各平台实际播放行为。

**功能控制面板**

主入口采用「设置 → 插件 → Paseo Essentials」，设置页标题为 `Features`，命令中心增加打开该页的快捷入口。页内依次为会话附件、图片查看、会话工具；继续使用 Paseo 原生设置组件、主题颜色和窄屏布局。只展示确有实现与可用性的控制项。

以下为建议默认值；旧设置中仍有对应受支持语义的值通过迁移保留。

| 分组 | 控制项 | 新装默认值 | 交互与依赖 |
| --- | --- | --- | --- |
| 会话附件 | 会话附件面板 | 开启 | 无附件时自动入口不出现；资源存在与能否预览分开判断 |
| 图片查看 | 纯图片消息聚合 | 开启 | 使用公开时间线渲染，图文混排局部聚合另列 API 缺口 |
| 图片查看 | 默认缩略图数量 | 3 张 | 保留 1–8 的有效范围；聚合关闭时不可编辑 |
| 图片查看 | 增强图片手势 | 开启 | 只影响增强手势，基本查看与按钮仍可用 |
| 会话工具 | 会话历史与导航 | 开启 | 提供公开列表与导航能力；已关闭会话重开需解决 API 缺口 |

现有快捷键替换和宿主菜单注入不继续作为可开启的兼容模式。当前公开 API 没有等价扩展点时，使用插件自有 header menu、Command Center 和按钮提供可用操作；如后续增加正式快捷键 API，再加入对应控制。

移动端是本次核心目标，不能用 native no-op 作为完成结果。每行区分配置、API 可用性和实际设备能力；同一 host 的授权客户端共享设置，不跨 host 同步，也不新增工作区覆盖层。视频和文档按正式预览能力显示操作，不能把设置已开启显示成已经支持播放。

设置使用即时保存。保存中防重复提交，失败保留真实已保存状态并给出重试；并发修改按 revision 检查，发生冲突后提示重新加载。恢复默认设置明确说明其影响。

关闭功能后，相关入口、订阅及临时 UI 按模块清理；已经打开的面板显示该功能已关闭并提供设置入口。新建会话、切换工作区、切换 host 和插件重载均按已保存值重新应用。插件整体启停继续使用 Paseo 自带开关。

**实现边界与关键验证**

图片聚合改用 `addTimelineTransformer` 与 `addTimelineRenderer`。当前 SDK 的替换粒度是整条消息，尚未提供复用宿主 Markdown 图片块的公开渲染扩展；因此首版建议只接管能够完整识别的纯图片消息，流式或图文混排内容继续使用宿主渲染，并可在附件面板集中查看图片。保留图文混排局部聚合需要官方块级扩展，不通过 DOM 隐藏原消息补回。

会话导航使用公开 `navigation.openAgent/openWorkspace`。Paseo 0.12 的公开 Agent handle 没有原 ID 重开方法；`refresh` 仅刷新快照，工作区恢复也不等于会话重开。当前解析 CLI 内部安装路径的方案需替换：优先补正式 SDK；若选择公开 CLI 适配，必须另行明确同 daemon 定位、安装要求与支持边界，不能宣称 SDK 无依赖。

第一步验证全窗口查看器、公开时间线聚合与设置接线、附件入口显隐三项跨平台接缝。未确认的正式扩展点不得用私有模块、猜测 HTTP 路由、直接宿主协议或全局事件补丁替代。

预期改动落在附件模型与识别/读取、设置契约、设置组件、原生查看器、时间线 renderer、client 注册及服务端索引。移除 `client/web.ts` 中对宿主 DOM、事件原型和菜单结构的依赖。保留旧 `media` 设置身份或提供显式迁移；`enabled` 和 `previewCount` 的受支持含义需保留。服务端对关闭能力的相关 RPC 作一致处理。

兼容目标是依赖公开 API 合约，而非绑定宿主次版本。最低版本由实际用到的 API 确定并验证 app/daemon 两端；不机械保留 `<0.12.0` 这类上限。未来未发生 API breaking change 时应具备继续工作的基础，但不能把未发布版本写成已经实测兼容。可选接口缺失时只停用依赖该能力的操作，不让整个插件崩溃。

实施顺序如下，未解决的 API 缺口在相关步骤前作明确决定。

1. 验证查看器、时间线渲染与按钮显隐的正式 API，确定会话重开的实现边界；视频播放器与对应资源访问扩展列入后续版本。
2. 实现统一附件索引、类型与可用操作，再完成查看器、设置、迁移及品牌文案。
3. 完成桌面、Web、iOS、Android 实际客户端验收，生成真实截图并整理上架候选版本。

**验收标准**

- 每个开关确实改变对应功能；独立项不会互相误关，关闭后释放对应资源。
- 确认空的会话没有自动附件入口；历史较早部分存在附件时仍能发现；加载、失败、替换历史、搜索无结果均不会误判为空。第一份附件出现后入口可通过事件更新，无需重载插件。
- 图片、视频、音频、PDF 与未知二进制都有正确分类和能力说明；缺少播放器或文件传输能力时不提供虚假的预览、打开或下载按钮。
- 视频的首发验收覆盖附件发现、分类与卡片展示；不要求内置播放，不将展示附件卡片描述为已支持播放。
- 旧 `media` 设置迁移保留原值；重载和重启后保留偏好；同 host 多客户端更新、revision 冲突及断线保存失败有明确结果；不同 host 互不影响。
- 在实际 app/daemon 组合上验证公开时间线渲染、附件分页、全窗口查看与导航；移除后的实现不依赖宿主 DOM、快捷键原型补丁或私有模块。
- 桌面拖动窗口、手机横竖屏、平板和 Android 折叠/分屏尺寸变化后正确适应；安全区域、触控缩放、切图、系统返回与焦点恢复逐项验收。
- 对声明支持的最早版本与当前稳定版本进行回归。移动端需覆盖真实 iOS 和 Android 客户端，缩窄桌面窗口不能替代设备验收；未具备的验收条件单独记录。
- 执行仓库既有 `pnpm check` 和打包检查，并补充必要的设置迁移、功能生命周期测试。浏览器夹具通过与真实 Paseo 验收分别记录。
- 读回候选包/commit 的 manifest、OVERVIEW、运行入口和媒体文件；核对市场提交材料，发布和市场审核结果各自记录。

证据包含当前插件源码、公开 SDK 0.11.1/0.11.2/0.12.0 声明、0.12.0 client API 源码及当前官方文档。候选实现已完成；静态、确定性测试与浏览器证据逐项记录，原生设备验收尚未完成。
