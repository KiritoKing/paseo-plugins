# 会话阅读实现约定

会话阅读属于 Paseo Essentials，只调整既有消息的呈现。原生侧栏、路由、composer、权限、模型与运行控制继续由 Paseo 管理。实现使用公开 timeline、settings 和 React Native API，消费宿主主题 token，不注册主题，不注入 DOM、全局事件或原型补丁。

## 内容归属

| 内容 | 呈现方式 |
| --- | --- |
| 已完成且受支持的助手正文 | 阅读组件呈现 Markdown、代码与复制操作 |
| 完整的纯图片消息 | 启用图片聚合时由图片库呈现，否则保留原生 |
| 流式正文、图片与文字混合、附件、不支持或超限内容 | 保留原生呈现 |
| 工具记录 | 默认保留原生分组；用户开启逐条样式后仅认领受支持的 shell 记录 |
| 思考记录 | 按偏好折叠或展开，保留完整原文和复制能力 |
| 全部折叠（仅输出） | 隐藏全部工具、思考及其标题，包括流式、未知和失败记录；不改变持久历史 |

正文、代码、列表和引用保持原始内容与顺序。复制读取完整原文，不只复制可见摘要。展开、折叠与复制不触发执行、重试、权限批准或额外模型调用。

## 设置与共存

安装 ID 为 `paseo-ux`，包名为 `@chlrc/paseo-ux`。阅读偏好使用独立的 `appearance` 设置、版本 1；媒体偏好继续使用 `media`。设置按所选 daemon host 保存，遵循公开 settings API 的 revision 冲突与 invalid 状态。

关闭会话阅读只释放其呈现贡献，不关闭附件、图片库或会话历史；关闭媒体也不改变阅读偏好。仅输出模式切回按类别设置后，恢复原先的工具与思考开关。

正文与图片库按内容分工，不依赖注册顺序。同类消息的多个呈现插件不能假定可以叠加：返回 `undefined` 才把认领机会交回宿主，空数组只用于用户主动选择的显示过滤。其他插件负责同类内容时，应关闭本模块对应类别，保留原生操作入口。

认领前校验内容、schema 和能力；注册失败后释放本模块的认领。renderer 缺失或组件异常不能当作可靠的原生回退机制。

旧设置的迁移是对应 daemon 上的管理操作，先备份，再保留完整 `appearance` 文件。运行模块不扫描其他插件设置，也不覆盖已有目标偏好。移除旧主题后，由 Paseo 自身处理主题回退。详见[迁移说明](migration.md#会话阅读并入-essentials)。

## 生命周期与验证

会话阅读只维护一份设置观察，不逐行建立订阅。重连重新读取设置；读取失败、能力缺失或卸载后停止认领。清理覆盖 transformer、renderer、设置入口与异步等待，较早请求不能在卸载后恢复贡献。

开发 SDK 为 0.11.2，最低 Paseo 要求为 `>=0.11.2`。声明范围不代表全部版本或设备已经实测。升级时重新核对公开接口和组合回归，不通过私有接口维持表面可用。

组合回归覆盖两种注册顺序、正文／纯图片／混合消息、流式状态、仅输出切换、独立功能开关、设置读取失败、重连、卸载及晚到响应。交互检查覆盖失败详情、完整复制、浅深主题与宽窄窗口；组件身份与展开状态不随普通流式更新重置。

本地检查、合成组件夹具、真实插件加载、原生实屏与设备验收分别记录。`running`、类型检查和截图都不能代替完整客户端交互验收，当前证据与缺口见 [Essentials 验证记录](../packages/paseo-ux/VALIDATION.md)。
